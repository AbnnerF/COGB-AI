COGB-AI

Bot de WhatsApp em Node.js com Baileys.

Para hospedar na Deplexo, consulte README-DEPLEXO.txt e mantenha deplexo.yaml e Dockerfile
na raiz do repositório. O aplicativo precisa ser criado como Worker.

Não envie arquivos .env, tokens, senhas ou chaves de API para o GitHub.
Configure ADMIN_NUMBER, BOT_NUMBER e demais credenciais como variáveis de ambiente no painel.
