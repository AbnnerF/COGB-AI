# CHAIM-BOT — Pokémon Beta 0.1

Nova versão: /pokemon mostra o perfil. Se o jogador ainda não escolheu um inicial, mostra a introdução e orienta usar /choose 1, /choose 2 ou /choose 3. A escolha fica salva em data/pokemon_players.json e não pode ser escolhida novamente. /mapa e /help p também foram adicionados.

Iniciais: Bulbasaur, Charmander e Squirtle.

Arceus, os trios e os grandes lendários ficam reservados para futuras atualizações.
